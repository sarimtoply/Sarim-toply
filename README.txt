- puro-heritage.html — your production-ready Puro Heritage build, linked from the Puro case study

1. Upload index.html and puro-heritage.html to the same public folder.
2. Rename index.html only if your host requires a different entry filename (most hosts expect index.html).
3. No build step is required.
